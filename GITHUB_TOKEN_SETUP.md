# Доступ к админ-панели через GitHub

1. Откройте GitHub: **Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**.
2. В **Repository access** выберите **Only select repositories** и отметьте `Arinaexe/zerna-coffee-demo`.
3. В **Repository permissions** задайте для **Contents** значение **Read and write**.
4. Нажмите **Generate token**, скопируйте токен и вставьте его в админку. Токен сохраняется только до закрытия вкладки браузера.

После сохранения изменения создают коммит в `main`. GitHub Pages обычно публикует обновления примерно за минуту.
